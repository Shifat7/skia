## Problem

AI coding tools can produce a working-looking diff faster than a reliable mental model forms. The hard part is often noticing:

- an abstraction, helper, or dependency the change did not need;
- a branch or error path hidden in a large generated diff;
- code that compiles and passes tests while the behavior is still unfamiliar;
- missing production detail such as retries, idempotency, error handling, or observability.

Skia is the intended checkpoint for one developer before that gap becomes a reviewer's problem.

## How it works

`skia review` is a documented command name. The shell in `src/main.ts` is unimplemented. The intended reading loop has four steps.

<Steps>

1. Read the simplified view. It is a map, and it is not executable.

2. Predict one result yourself, before any feedback.

3. Compare that answer with the source-backed evidence.

4. Open the original code wherever coverage is `partial`, `unmapped`, `unsupported`, `failed`, or `unchecked`.

</Steps>

## FAQ

<div class="faq">
	<details>
		<summary>Is Skia installable as a review CLI yet?</summary>
		<p>No. The package is private at 0.0.0, and the shell does not run <code>skia review</code>. There is no working global npm install, Homebrew formula, or curl installer. Foundation checks for contributors are on <a href="/skia/contribute/">Contribute</a>.</p>
	</details>
	<details>
		<summary>Is it local-first?</summary>
		<p>The foundation keeps snapshot and parse artifacts local. Skia does not operate a review backend and does not send product telemetry. A future repository mode may send bounded context only to a model endpoint you configure, after consent. <a href="/skia/privacy/">Privacy</a> has the egress matrix.</p>
	</details>
	<details>
		<summary>Which languages can it read?</summary>
		<p>Supported source languages are exactly TypeScript, TSX, and Python. Anything else stays <code>unsupported</code> rather than being summarized as if it had been analyzed.</p>
	</details>
	<details>
		<summary>Is this Google's Skia?</summary>
		<p>No. This repository is a comprehension checkpoint. It is a different project from Google's Skia graphics library. The shared name is an open release risk (<a href="https://github.com/Shifat7/skia/blob/main/docs/OPEN_DECISIONS.md">OD-1</a>), not an affiliation.</p>
	</details>
</div>
